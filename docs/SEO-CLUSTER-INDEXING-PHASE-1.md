# SEO Cluster & Indexing — Phase 1

## Scope
Strengthen the existing Marqués organic-search ecosystem without adding new public routes or changing the Home or Partners design.

## Core intent map
- `/residency` — Costa Rica residency; broad residence pathways with Investor Residency as a commercial focus.
- `/residency/about-costa-rica` — living in Costa Rica; long-term residence, lifestyle and real-asset context.
- `/residency/real-estate` — Costa Rica residency by investment and the relationship with qualifying real estate.
- `/real-estate` — Costa Rica real estate for international buyers; property advisory independent from residence eligibility.
- `/investments` — Costa Rica investment opportunities and real assets; institutional/private-capital context.

## Internal-link cluster
`/residency` ↔ `/residency/about-costa-rica` ↔ `/residency/real-estate` ↔ `/real-estate` ↔ `/investments`

Existing contextual links remain in place. Phase 1 adds:
- Real Estate and Investments to the residency contextual navigation.
- Residence by Investment as a pathway from Investments.

## International SEO
The existing architecture remains authoritative:
- English: unprefixed URLs
- Spanish: `/es`
- French: `/fr`
- Simplified Chinese: `/zh-hans`
- reciprocal hreflang and x-default are generated by the existing international SEO system
- sitemap remains production-only and generated from the existing public-route allowlist

Phase 1 adds query-intent-focused metadata overrides for the five core cluster pages in ES/FR/ZH-Hans and sharpens English metadata for the same cluster.

## Production indexing procedure after approval
Do not submit Preview URLs to search engines.

After the approved branch is merged and the production deployment is verified:
1. Verify `https://marquescr.com/robots.txt` and `https://marquescr.com/sitemap.xml` return 200.
2. Resubmit `https://marquescr.com/sitemap.xml` in Google Search Console and Bing Webmaster Tools.
3. Inspect/request Google indexing for the priority URL families below, prioritizing the core residence cluster.
4. Submit the changed production URLs through the existing IndexNow post-deployment workflow.
5. Verify Bing URL Inspection / IndexNow processing and Google URL Inspection status.
